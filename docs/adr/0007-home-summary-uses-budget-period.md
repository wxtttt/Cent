# 首页与统计按预算周期汇总，而非自然月

首页「本月支出」与统计页的月度汇总，一律按账本当前的预算周期（由 `budgetStartDay` 切分）取数，不再使用自然月 1 号到月末。

## Status

Accepted

## Considered Options

- **保持自然月全口径**：否决 —— 起始日改成 5 日后，预算页周期是 11/5–12/4，首页是 11/1–11/30，两边连时间范围都不同，用户无法对账。
- **自然月 + 一行口径说明**：否决 —— 只解释差额，数字仍然对不上。
- **改成预算口径之和**（普通预算已用 + 各特殊预算已用）：否决 —— 没建预算的月份会少算；且 ADR-0001 的孤儿回落让归属随「当月有没有对应预算」漂移。
- **按预算周期做全口径汇总**：采用。

## Consequences

- UI 上的「本月」必须同时标出实际周期（如「11/5–12/4」），否则用户仍会按自然月理解这个数字。
- 过渡周期可达 40~51 天，该月支出会显著偏高；周期标题必须标注「过渡周期」，否则会被误读为突然超支。
- 统计页的月度分组、导出、同比环比都要按记录自带的 `periodStart` / `periodEnd` 取数，不能复用 `dayjs().startOf('month')`。
- ADR-0001 的互斥只影响「预算归属」，不影响首页全口径：首页仍汇总周期内所有支出，含特殊预算的账单。
