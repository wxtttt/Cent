# 特殊预算与普通预算互斥计账

带特殊标签的账单只计入对应的特殊预算，不再计入当月普通预算。这样每条预算都是账本支出里互不重叠的一片切片，可以直接相加。

## Status

Accepted

## Considered Options

- **双计**：普通预算是全口径，特殊预算是其中一片切片。否决 —— 同一笔钱会同时出现在两个进度条和两个「本月支出」里，用户无法判断总额是否重复计过。
- **每条预算自行配置标签过滤**：沿用现有 `onlyTags` / `excludeTags`。否决 —— 与「标签只分普通/特殊两类」的简化目标冲突，每建一条预算都要手工选标签。
- **全局互斥**：普通预算统一排除所有特殊标签，账单归属由标签类型决定，无需逐条配置。采用。

## Consequences

- 普通预算的「本月支出」不再等于账本全口径支出；统计与首页必须另外提供独立的全口径数字，否则用户会以为漏账。
- **例外**：只有当月存在「关联了该特殊标签」的特殊预算时，这笔账单才被排除出普通预算；否则回落到普通预算。这是刻意的选择，不是漏判 —— 否则预算被删或还没建时，这笔钱会从所有预算里蒸发。代价是同一个特殊标签的账单在不同月份可能归属不同。
