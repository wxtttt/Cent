# 删除自定义标签组，标签只分普通与特殊

标签不再支持用户自定义分组；标签只有「普通」与「特殊」两种，由标签自身的类型字段决定。原 `BillTagGroup`（组名、颜色、包含标签、单选、必选）及其 CRUD、记账页分组选择器、预设合并逻辑全部移除。

## Status

Accepted

## Considered Options

- **保留数据、只撤 UI**：字段留着将来能恢复，但会长期留下一套没人用的死代码与脏数据。否决。
- **把三条约束挂到标签上**：能力保住，但要写字段迁移，且「必填」离开「组」这个概念后无从定义。否决。
- **改造成固定的普通/特殊两段**：复用分组渲染器，等于用一套通用机制去实现一个不可变规则。否决。
- **彻底删除**：采用。

## Consequences

- 应用尚未上线、无历史用户数据（见 ADR-0004），因此不需要迁移：`GlobalMeta.personal[uid].tagGroups` 直接清空，`GlobalMeta.tags` 保留。
- 「特殊标签互斥」需要作为硬规则在新的标签选择器里重新实现 —— 删掉的只是可配置的单选，不是单选行为本身。
- 标签选中时自动切换币种（`BillTag.preferCurrency`）原本由分组选择器触发；本次一并删除该字段及其 i18n、预设合并逻辑，不再重新实现。
