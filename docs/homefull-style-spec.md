## 2. 标志性组件

### 2.1 票券卡（Ticket Card，xmui/ticket_card）
- 白底大圆角卡；**垂直虚线分隔处左右两个半圆打孔缺口**（背景色圆形挖空）。
- 卡顶部左侧压一条**米黄色胶带贴纸**（半透明斜贴，约 120×28px，旋转 -3°）。
- 卡右上/左下有**淡黄/淡绿渐变圆角**装饰角 + 小星形装饰（✦）。
- 卡顶中央可有**吉祥物探头**（每业务域专属：首页=小暖、记账=小鸡、知物=小智、财富=小盈、有期=小齐、归医=小绿猫）。
- 用途：11月收支卡、资产总览卡、财富总览卡、一事一念卡。

### 2.2 分段控件（页面级 Tab）
- 整体一个**浅奶茶色圆角容器**（高约 76px 实机 = 38dp）。
- 激活项：**白色凸起胶囊**（带阴影、深色粗体文字）；未激活：透明底灰棕文字。
- 归医页是 3 段（健康档案/药箱/就诊记录），知物 3 段（全部/实物/虚拟），财富 4 段（总览/资金账户/股票/实物金属），有期 2 段（待办/纪念），记账抽屉 3 段（支出/收入/转账）。

### 2.3 底部 Dock（全局，一级页签页显示）
- 白色大圆角长条固定底部：左侧**当前页签吉祥物小图** + 占位文案（首页="长按这里，语音输入一件事"/记账="问问家小满，或者直接说…"/AI 建议轮换="猜你想问：这个月花了多少"）+ 麦克风圆形浅灰钮 + **深色加号圆钮**。
- 加号点开弹出**创建菜单**：相册 / 拍照 / 账单导入 / 手动创建 四张白卡（icon 上、文字下）。
- 吉祥物随当前 Tab 切换（首页小暖橙猫 / 归医小绿猫 / 知物小蓝猫 / 财富小盈柴犬 / 有期小紫猫）。

### 2.4 头部
- 顶部：圆形头像（左）+ 页面名居中粗体 + 圆角方形白底 AI 按钮（右）。
- 一级 Tab 行：APK 为 6 个等宽（首页/记账/归医/知物/财富/有期）；Cent 落地 4 个（首页/记账/归医/知物，财富无对应物、有期暂不独立成页）。
- 二级页（行车能耗）：**白色背景**（无暖底）、白色圆形返回钮居左、标题居中粗体。

### 2.5 空态
- 列表空态为**纯文字居中灰字**（"暂无记账记录"/"还没有成员档案"/"今天暂无提醒"），无插画。
- 引导型空态：icon + 黑粗标题 + 说明文字 + 橙色大圆角主按钮（行车能耗"还没有添加车辆"）。

## 3. 页面规格

### 3.1 首页
1. 问候带（2026-11-07 用户定稿：**常驻折叠态，不做展开/动画**）：全宽奶油带（ground-muted）+ SVG 波浪下缘；带内一行——「早安，」+ 用户名（17px bold 暖棕）｜右侧小暖吉祥物 + 协作者头像叠放，头像右下角橙色⇄徽章 = 换账本入口。无日期行。
2. 概览卡：白卡 rounded-panel p-4，**无「概览」标签**；中缝细分隔线；左列（本月支出 13px 灰表头 + ¥0 32px bold 暖棕 + 4px 高进度条）｜右列（今日待办 + 0/0 + ○今日已完成0%）；两列 flex-col + 底行 mt-auto 保证**等高对齐**。
3. 今日总结卡：胶带贴纸 + 右上小鸡探头 + 橙色 icon+「今日总结」17px bold 标题 + 正文 14px + bullet 行 13px。
4. 近期提醒：16px bold 标题；空态纯文字居中 12px。
5. dock 加号创建菜单按页面上下文切换：知物页首项为「添加物品」。

### 3.2 记账页
- 筛选胶囊（左上，白底+chevron-down）｜分析胶囊（右上，图表 icon+分析）。
- 11月收支票券卡：标题特大粗体；右上「结余」小字+金额粗体（黄色扇形角）；中列 本月收入（红）｜虚线｜本月支出（绿）大粗体；打孔虚线；底列 结余率/预算率/收入比 三列（标签小字+数值粗体+灰进度条）。
- 记录列表空态：左对齐灰字「暂无记账记录」。

### 3.3 记账抽屉（手动创建）
- 白底圆角顶 sheet + 灰色拖拽把手。
- 段选：支出｜收入｜转账（激活灰白凸起）。
- 分类快捷卡：白色大圆角卡，5 列（4 分类+更多灰圆 ⋯），分类用 **3D 拟物插画图标**（约 56px）。
- 胶囊行：📅 日期时间胶囊 ｜ 💰 现金钱包胶囊（圆角白底描边）。
- 金额行：绿色 ¥0 特大粗体 + 右侧灰占位「点击填写备注」。
- 键盘：4 列（1-9 / . 0 ⌫），右列 + − 运算符；**完成键橙色大块跨两行**（圆角矩形）。

### 3.4 归医（医疗）
- 段选：健康档案｜药箱｜就诊记录 + 右侧圆形搜索钮。
- 标题「家庭健康档案」黑粗大字 + 右侧小绿猫吉祥物。
- 空态纯文字「还没有成员档案」。

### 3.5 知物（物品清单）
- 筛选胶囊 + 段选：全部｜实物｜虚拟。
- 资产总览票券卡：标题大粗；总资产(元) 0.00 橙色特大粗 ｜ 虚线 ｜ 日均成本(元) 0.00 棕色特大粗；打孔虚线；下排 使用中/停用中/已处置 三列（标签+数字，使用中数字绿色）。
- 物品状态三态：使用中/停用中/已处置（非两态）。
- 分类空态「暂无分类」纯文字。

### 3.6 财富
- 段选：总览｜资金账户｜股票｜实物金属。
- 免责提示条：浅卡 ℹ️ 财富数据仅做资产记录展示，不构成任何投资建议 + ×。
- 财富总览票券卡：标题粗+眼睛按钮；总资产(元) 0 特大粗；打孔虚线；资金资产(元)｜投资资产(元) 两列。
- 资产详情 section + 资金账户卡（资金资产/账户数量/本月流入）。

### 3.7 有期（待办）
- 筛选胶囊 + 段选：待办｜纪念。
- 一事一念票券卡：标题特大粗 + 右上 0（橙色特大）件待完成；副文案「每件小事，都是对家的一份用心」；打孔虚线；进度条；四态图例：● 进行中（橙）● 搁置（灰）● 已完成（绿）● 已延期（红）+ 数值。
- 待办事项 section + 右侧「管理」（排序 icon+文字）。
- 待办状态四态：进行中/搁置/已完成/已延期。

### 3.8 行车能耗（车辆，二级页）
- 白底子页；白色圆形返回钮；标题居中粗体。
- 空态：汽车 icon（灰）+「还没有添加车辆」黑粗体 + 说明「添加车辆后，每次加油或充电记一笔，就能算出油耗和每公里花费」+ 橙色大圆角「添加车辆」按钮（全宽约 60%）。

### 3.9 个人中心
- **左侧 85% 抽屉**（覆盖在页面上，右侧露出页面），浅底白卡无边框。
- 用户行：头像 + 昵称粗体 + 右箭头（进设置），无 AI/关闭按钮。
- 月历卡：2026年11月（18px bold，点击回本月）+ 🔥连续 N 天橙色胶囊；**左右滑动切月**；日网格 7 列（格 36px、数字 13px；今日=20px 橙底白字小圆+白环+橙环，总圈约 26px；未来日期浅灰）；底部三列 记录天数/总记录/连续天数（20px bold，连续天数橙色）。
- 更多功能九宫格（顺序对齐）：预算管理/分类管理/首页设置｜账本管理/行车能耗/贷款计算｜标签/货币/数据｜主题/设置（24px 线性 icon+13px 文字）。
- 快捷记账三列：账单导入/自动记账/定时记账。
- 归医/知物在 Cent 中是页签，不放宫格。

## 5. Cent 对齐执行清单

按用户优先级：记账抽屉 > 物品清单 > 医疗 > 车辆 + 首页。

1. 全局：底色 #fbf7ef；票券卡组件（打孔+胶带+装饰角）；分段控件组件；dock 吉祥物随页签切换 + 加号弹创建菜单。
2. 记账抽屉：完成键跨两行橙色；分类快捷卡 5 列；日期/钱包胶囊行样式对齐。
3. 记账页：11月收支卡改票券卡（打孔+胶带+吉祥物探头+结余角标）；筛选/分析胶囊对齐。
4. 物品清单：**页签页**（无返回头）「资产总览票券卡」+ 三段（全部/实物/虚拟）+ 物品三态（使用中/停用中/已处置）。
5. 医疗：**页签页**三段（健康档案/药箱/就诊记录）+ 搜索钮 + 标题+小吉祥物。
6. 车辆：二级页白底 + 图标空态 + 橙色大按钮（入口在个人抽屉宫格）。
7. 首页：常驻波浪问候带、今日总结卡（胶带+探头+橙标题）、近期提醒、概览卡两列等高。
8. 2026-11-07 修订：归医/知物升级为页签；个人抽屉对齐 APK（白卡无边框+日历滑动+宫格重排）；字体回系统默认栈并去 Instrument Sans；弹层基准 z=4，页面内探头类装饰不得使用高 z-index。
