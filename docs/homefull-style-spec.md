## 2. 标志性组件

### 2.1 票券卡（Ticket Card，xmui/ticket_card）
- **奶白对角渐变底**（左下暖米 #f8edde → 右上 #fffdf6）大圆角卡；**垂直虚线分隔处左右两个半圆打孔缺口**（背景色圆形挖空）。
- 卡顶左侧压一条**半透明和纸胶带**：纯色约 #ecd592 / 不透明度 0.72，实测合成色卡外 #eedaa6、卡内 #f2e1b1（首页 #f0dfad / #f2e1af）；**APK 原图胶带包围盒 181×58px、卡片宽 964px**（记账/知物/首页三页完全一致），折算到 360px 卡片即约 68×21px、宽高比 3.12；**左端距卡片左沿约 23px**，旋转 -4°，**骑跨卡片上沿**（卡外约 10px / 卡内约 11px）。实现用 66×17px 的 SVG 框（路径端点铺满 viewBox，旋转后包围盒约 67×22px）。**轮廓（APK 原图倾斜校正后逐行取值）：上下两条边是完全平直的直线**（校正后波动 < 1px），**左右两端各有 2 个 V 形凹口**（凹深约 5% 宽度）、中间夹一个尖角，即每端形状为「上尖角 → V 凹 → 中尖角 → V 凹 → 下尖角」；**不要在上下缘加锯齿**。中间一条浅色水平折痕（卡顶边透过胶带显出的底色分界），因胶带整体旋转 -4°，SVG 内需反向补偿画成斜线才能保持屏幕水平。禁止用实心直角矩形，撕口也不能切太深（会吃掉视觉长度）。
- **每个 tab 的统计卡渐变是镜像/差异化布局，不能共用一个模板**（APK 1080×2340 逐页取样；扇形纯色实测淡黄 #faefcf / 淡绿 #ecf0e5，色值相同但位置与渐变方向不同）：

  | tab / 卡 | 卡底暖米渐变 | 淡黄大扇形 | 淡绿小扇形 | 星形 ✦ |
  | --- | --- | --- | --- | --- |
  | 首页 今日总结 | 纯奶白（极淡 #fbf9f1→#fffdf6） | 无 | 无 | 无 |
  | 记账 11月收支 | **左下** #f8edde → 右上 #fffdf6 | **右上** | **右下** | 右上 + 左下（黄） |
  | 知物 资产总览 | **右下** #fbf4e9 → 左上 #fffdf6 | **左上** | **左下** | 右上 + 左下（黄） |
  | 财富 财富总览 | **右下** #fbf4e8 → 左上 #fffdf6 | **左上** | **左下** | 右上 + 左下（黄） |
  | 有期 一事一念 | 纯奶白 | **右下** | **卡顶中央** | 右上 + 左下（黄） |
  | 归医 | 无统计卡 | — | — | — |

  实现为 `TicketCard` 的 `variant`（home/ledger/inventory/wealth/todo）：卡底渐变用 `--dp-gradient-ticket-*`，扇形圆心固定在圆形元素中心、靠定位落到指定角，星形统一黄色 #e8c66a。扇形是**实色硬边弧**（radial 实色到 86% 半径，最后 14% 淡出做抗锯齿），不要做大面积渐隐。
- **卡顶吉祥物按 tab 差异化**（APK 原图 1080×2340 逐只取色测包围盒，按 1080→393 CSS px 折算）。只有首页今日总结卡是完整立绘**压在卡片上**，其余 tab 都是半身探头图，**切口正好贴卡片顶边、不覆盖卡片**：

  | tab / 卡 | 姿态 | APK 可见尺寸 | 水平位置（占卡宽） | 与卡顶的关系 |
  | --- | --- | --- | --- | --- |
  | 首页 今日总结 | 小暖**完整坐姿** | 51×58px | 89%（右上） | 跨卡顶：卡外露 22px / 探入卡内 37px |
  | 记账 11月收支 | 小鸡半身探头 | 45×46px | 50%（居中） | 切口贴卡顶，不覆盖 |
  | 知物 资产总览 | 小智半身探头 | 47×45px | 79%（靠右） | 同上 |
  | 财富 财富总览 | 小盈半身探头 | 42×45px | 40%（偏左） | 同上 |
  | 有期 一事一念 | 小齐半身探头 | 48×46px | 68%（偏右） | 同上 |
  | 归医 | 小绿猫完整坐姿 40×38px | — | 无统计卡，放在「家庭健康档案」标题右侧 |

  实现为 `TicketCard` 的 `VARIANTS[variant].mascot`（`anchor` 水平位置 + 卡顶偏移，`height` 立绘框高），尺寸由组件统一控制，页面只传 `h-full w-auto` 的 `<img>`。知物页卡片上边距需放大到 `mt-9`，否则靠右的猫头会顶进上方「虚拟」胶囊（APK 实测胶囊底与猫顶垂直错开约 4px）。
- 用途：11月收支卡、资产总览卡、财富总览卡、一事一念卡。

### 2.2 分段控件（页面级 Tab）
- 整体一个**浅奶茶色圆角容器**（高约 76px 实机 = 38dp）。
- 激活项：**白色凸起胶囊**（带阴影、深色粗体文字）；未激活：透明底灰棕文字。
- 归医页是 3 段（健康档案/药箱/就诊记录），知物 3 段（全部/实物/虚拟），财富 4 段（总览/资金账户/股票/实物金属），有期 2 段（待办/纪念），记账抽屉 3 段（支出/收入/转账）。

### 2.3 底部 Dock（全局，一级页签页显示）
- 白色大圆角长条固定底部：左侧**当前页签吉祥物小图** + 占位文案（首页="长按这里，语音输入一件事"/记账="问问家小满，或者直接说…"/AI 建议轮换="猜你想问：这个月花了多少"）+ 麦克风与加号均为浅灰白圆钮（#f6f6f6）+ 深色图标。
- 加号点开弹出**创建菜单**：相册 / 拍照 / 账单导入 / 手动创建 四张白卡（icon 上、文字下）。
- 吉祥物随当前 Tab 切换（首页小暖橙猫 / 归医小绿猫 / 知物小蓝猫 / 财富小盈柴犬 / 有期小紫猫）；**框 30×30px**（APK 实测可见约 25×26px），`object-contain`。

### 2.4 头部
- 顶部：圆形头像（左）+ 页面名居中粗体 + 圆角方形白底 AI 按钮（右）。
- 一级 Tab 行：APK 为 6 个等宽（首页/记账/归医/知物/财富/有期）；Cent 落地 4 个（首页/记账/归医/知物，财富无对应物、有期暂不独立成页）。
- 二级页（行车能耗）：**白色背景**（无暖底）、白色圆形返回钮居左、标题居中粗体。

### 2.5 空态
- 列表空态为**纯文字灰字**，无插画、无引导按钮：记账「暂无记账记录」**左对齐**且票券卡下方不设「记录」标题栏；归医「还没有成员档案」、知物「暂无分类」、首页「今天暂无提醒」居中。
- 零值缺省：金额显示 ¥0 / 0.00；**预算未设置显示「未设置」**而非 0%，进度条保持空轨道。
- 引导型空态：icon + 黑粗标题 + 说明文字 + 橙色大圆角主按钮（行车能耗"还没有添加车辆"）。

## 3. 页面规格

### 3.1 首页
1. 问候带（2026-11-07 用户定稿：**常驻折叠态，不做展开/动画**；2026-11-09 补渐变）：全宽奶油带 + SVG 波浪下缘；带内为左 #e7e0cb → 中 #f0dbc1 → 右 #f2e2c3 的横向渐变，叠右上黄圆 #f0d58b 径向渐变、左下青绿弧 #c0d2bf 径向渐变（展开态 hero 的缩小版），右半保留斜切分界；带内一行——「早安，」+ 用户名（15px bold 暖棕）｜右侧小暖吉祥物（框 46px，APK 可见约 38×41px）+ 协作者头像叠放，头像右下角橙色⇄徽章 = 换账本入口。无日期行、无展开态大猫。
2. 概览卡：白卡 rounded-panel p-4，**无「概览」标签**；中缝细分隔线；左列（本月支出 13px 灰表头 + ¥0 32px bold 暖棕 + 4px 高进度条）｜右列（今日待办 + 0/0 + ○今日已完成0%）；两列 flex-col + 底行 mt-auto 保证**等高对齐**。
3. 今日总结卡：胶带贴纸 + **右上橙猫小暖（完整立绘，框 64px / 可见约 54×56px，跨卡顶压进卡内约 34px；全站唯一覆盖卡片的猫）** + 橙色 icon+「今日总结」15px bold 标题 + 正文 13px + bullet 行 12px；渐变底但无关角扇形。
4. 近期提醒：16px bold 标题；空态纯文字居中 12px。
5. dock 加号创建菜单按页面上下文切换：知物页首项为「添加物品」。

### 3.2 记账页
- 筛选胶囊（左上，白底+chevron-down）｜分析胶囊（右上，图表 icon+分析）。
- 11月收支票券卡：标题特大粗体；右上「结余」小字+金额粗体（黄色扇形角）；中列 本月收入（红）｜虚线｜本月支出（绿）大粗体；打孔虚线；底列 结余率/预算率/收入比 三列（标签小字+数值粗体+灰进度条）。
- 记录列表空态：左对齐灰字「暂无记账记录」，票券卡下方无「记录」标题栏与「共计 N 条」，无插画/按钮。
- 底行三列：结余率 0%｜预算率 **未设置**（无预算时）｜收入比 0%。

### 3.3 记账抽屉（手动创建）
- 白底圆角顶 sheet + 灰色拖拽把手。
- 段选：支出｜收入｜转账（激活灰白凸起）。
- 分类快捷卡：白色大圆角卡，5 列（4 分类+更多灰圆 ⋯），分类用 **3D 拟物插画图标**（约 56px）。
- 胶囊行：📅 日期时间胶囊 ｜ 💰 现金钱包胶囊（圆角白底描边）。
- 金额行：绿色 ¥0 特大粗体 + 右侧灰占位「点击填写备注」。
- 键盘：4 列（1-9 / . 0 ⌫），右列 + − 运算符；**完成键橙色大块跨两行**（圆角矩形）。

### 3.4 归医（医疗）
- 段选：健康档案｜药箱｜就诊记录 + 右侧圆形搜索钮。

- 空态纯文字「还没有成员档案」。

### 3.5 知物（物品清单）
- 筛选胶囊 + 段选：全部｜实物｜虚拟。
- 资产总览票券卡：标题大粗；总资产(元) 0.00 橙色特大粗 ｜ 虚线 ｜ 日均成本(元) 0.00 棕色特大粗；打孔虚线；下排 使用中/停用中/已处置 三列（标签+数字，使用中数字绿色）。

### 3.6 财富
- 段选：总览｜资金账户｜股票｜实物金属。

- 资产详情 section + 资金账户卡（资金资产/账户数量/本月流入）。

### 3.7 有期（待办）
- 筛选胶囊 + 段选：待办｜纪念。
- 一事一念票券卡：标题特大粗 + 右上 0（橙色特大）件待完成；副文案「每件小事，都是对家的一份用心」；打孔虚线；进度条；四态图例：● 进行中（橙）● 搁置（灰）● 已完成（绿）● 已延期（红）+ 数值。
- 待办事项 section + 右侧「管理」（排序 icon+文字）。
- 待办状态四态：进行中/搁置/已完成/已延期。

### 3.8 行车能耗（车辆，二级页）
- 白底子页；白色圆形返回钮；标题居中粗体。
- 空态：汽车 icon（灰）+「还没有添加车辆」黑粗体 + 说明「添加车辆后，每次加油或充电记一笔，就能算出油耗和每公里花费」+ 橙色大圆角「添加车辆」按钮（全宽约 60%）。

### 3.9 个人中心
- **左侧 80% 抽屉**（APK 实测右边界 ≈ 原图 x=870/1080），中性灰白体系：背景 `#f4f4f4`、卡片 `#ffffff`、主文字/图标 `#383230`、次级 `#8a847f`、分隔线 `#efeae5`；与首页暖米主题**隔离**（`.dp-drawer-surface` 仅在亮色下局部覆盖语义变量，暗色沿用暗色 token）。白卡无边框；卡片左右各留 20px、卡内左右 20px / 上下 14px、卡片间距 16px，宫格用 `-mx-5` 铺满整卡宽（3 列各约 91px）。
- 用户行：**42px 圆形头像 + 16px 常规昵称 + 20px 右箭头**（进设置），无 AI/关闭按钮。APK 现场实测（1080→393 CSS）：头像圆 x=24..65 直径 42px、昵称字高 11px（约 16px 字号）、箭头 20px；系统状态栏 24px，其下头像上留 12px、下留 21px，日历卡顶 y=98，即内容区净高 **74px**。网页无系统状态栏，故 `pt=12 + 42 + pb=20 = 74px`；抽屉卡片左边界 x=20、头像左 x=24，用户行单独 `pl-6 pr-5`，昵称起点 x≈78（APK 76）。第 20 条整页收紧时曾误压到 32/14/16px、行高仅 55px，第 22 条按现场实测回改。
- 月历卡：月份标题 15px **bold** + 🔥连续 N 天 11px 胶囊（**仅连续 ≥1 天时出现**）；星期行 12px；日网格 7 列，格与行距均 **31px**、数字 13px；**左右滑动切月**。**判定规则**：橙色实心内圈（23px 橙底白字）只在「当天有账单」时出现；今天恒有外圈（三层 **31/27/23px**，橙环与白环各 2px 整数；不可用 1.5px 环宽，DPR=1 下会亚像素取整导致左上半圈发淡、白环断开），当天没记账时内圈改为卡片同色 + 橙字，只剩空心外圈；非今天有账单=23px 实心橙点、无账单=纯数字；未来日期浅灰。底部三列（16px bold 数字 + 11px 单位 + 13px 标签，连续天数橙色）是统计数值而非标识，0 照常显示。
