# 本 fork 的定制现状

> 由根目录 `AGENTS.md` 拆分而来，属于功能级文档（渐进式披露）。先读 `AGENTS.md` 了解全局约定，改到本模块时再读本文；本模块有新口径 / 新规则时，同步更新 `AGENTS.md` 索引与本文。

## 定制现状

相对上游，本 fork 已重做：

- 全局壳层：顶部头像 + 搜索胶囊（取代应用名，跳 /search）+ 35px 白圆 AI 入口 + 居中对称的首页/记账/归医/知物 Tab（单条滑动下划线）+ 底部 dock（吉祥物随页签、加号按页签与子页签分派）；四个页签页由 `components/tab-pager` 承载跟手横滑（`components/app-chrome`）。
- 首页：hero 大字问候（滚动折叠吸顶）、票券式今日总结、近期提醒、概览卡（`pages/home`）。
  - **概览卡左栏支出标题固定为「本月支出」**（key `month-expense`），标题后**不带任何日期 / 周期范围**；金额仍按「当前日所在记账周期」统计（`pages/home` 的 `budgetPeriodStart/End`：优先读当前普通预算记录的冻结边界，回落 `periodContaining(now, clampStartDay(startDay))`）。用户明确不要改回「本期支出」、也不要在标题后补日期；周期范围只在预算页 / 记账页展示。
- 记账页与分析页：票券式月度收支卡、筛选/分析胶囊、统计视图（`pages/ledger`、`pages/stat`、`components/stat`）。
- **记账页配色与日头**（APK 1080×2340 现场取色，`pages/ledger` + `components/ledger`）：① 页面根节点挂 `dp-home-surface`，账单卡与筛选/分析胶囊因此拿到奶白 `#fffdf6`（票券卡自身用渐变、不受影响），全局 `--dp-color-panel` 仍保持纯白；② 筛选/分析胶囊按 APK 实测是**无边框、无阴影**的奶白圆角块，文字与图标同为深暖灰（`text-ink-secondary`），**分析图标不要用 `text-brand` 橙**；③ 账单卡（`components/ledger/item.tsx` 的 `BaseBillItem`）按 APK 实测**扁平无阴影**（去掉 `shadow-panel`），只留 1px `border-rule` 暖色描边 + `rounded-3xl`；④ 票券卡下方有账单时显示**「明细记录」**小标题（`t("records")`，15px `text-ink-warm`），空态不显示；⑤ 日头日期按 APK 实测：当天显示「今天」，其余显示「M月D日」（如 `11月10日`），跨年才带年份——**不要用「10日」或「11-10」**，这段逻辑写在 `components/ledger/index.tsx` 的 `DayHeader` 里，不要改全局 `denseDate`（预算区间仍用它）。⑥ **明细卡只渲染时间 `HH:mm`、不带日期**（APK 明细卡无日期，日期由日头承载）：`BaseBillItem`/`BillItem`/`Ledger` 的 `timeOnly` prop，仅记账页传入；搜索页等无日头场景仍走 `denseTime`。⑦ **明细卡金额恒补两位小数**（无小数补 `.00`，APK 恒显 `-¥20.00`）：`Money` 的 `pad` prop（`accurate` 路径 `toThousand(value, 2)`），账单卡主金额与折算金额都传。⑧ **支出语义色按 APK 实测改 `#25c454`**（亮，`index.css` `--color-expense`；暗色推导 `#4ade80`），原 `#1f9d63` 偏暗偏青被用户指出与 APK 不一样；收入红不变。
- 个人中心抽屉（`components/profile`，含物品/医疗/车辆/贷款/自动规则入口，关于胖记位于抽屉最底部；首页高级功能推广与 buy me coffee 已移除）。APK 现场实测规格：`w-[80%] max-w-[340px]`；用户行 42px 头像 + 16px 昵称 + 20px 箭头、净高 74px；日历 31px 日格 / 31-27-23px 圆环，橙内圈仅在当天有账单时出现、连续记录徽章仅在 `streak>=2` 时出现（用户要求连续两天及以上才显示「连续」标签，仅 1 天隐藏；下方「连续天数」数值指标不受影响仍显示真实天数）；宫格 67px 行高 / 91px 列间距 / 20px 图标 / 12px 标签，卡片间距 16px。胖记保留 11 个功能项（APK 仅 7 项），第 7 位固定「贷款计算」以对齐前 3 行 3+3+1 结构。完整逐项实测与 22 条修订记录见 `docs/homefull-style-spec.md`。
- 四个一级页签页的列表缺省态统一为**纯文字**（不配插画、引导按钮或「共 N 笔」栏）；空态文案有专用 i18n key，勿复用其它页面的键。
- 暖色设计令牌与深色模式（`index.css`）。
- 记账底部抽屉：日期/币种/标签胶囊、内联备注（含自动规则建议胶囊）、滚轮日期选择器、4×4 键盘、下拉关闭（`components/bill-editor`、`wheel-date-picker`、`components/keyboard.tsx`、`components/ui/dialog/index.tsx`）。一级分类为无图标的纯文字分组块，二级分类用彩色插画。
- 账单分类（`ledger/category.ts`）：两级结构，一级 12 个分组无图标，二级 42 个分类（37 支出 + 5 收入）名称与插画取自家小满分类模板；`id` 与 WebP 文件名统一为英文语义 slug，存于 `public/category/`（默认 42 张 + 可选 61 张 = 103 个文件、约 352 KiB）。分类管理页（`components/category/list.tsx`）为「分类管理」：胶囊支出/收入 tab、白卡列表、白底分节标题行（仅拖拽手柄） + 红减号/插画/名称/方框铅笔/拖拽的子项行，无折叠。子项编辑笔用 `icon-[lucide--square-pen]`（圆角方框 + 斜笔），不是单支 `pencil`。`use-category.ts` 以当前默认表为准，仅叠加 UUID 形式的用户自建分类；旧分类 ID 与历史账单不做兼容。页面配色由 `index.css` 的 `.dp-category-surface` 局部作用域提供（#f4f4f4 底 / #ffffff 卡 / #18181b 文字 / #ef4444 减号 / #f0f0f0 分隔线），右上角不提供重置入口，子项行高 54px。**一级分组固定不可增删改**：标题行没有加号/铅笔，也不能通过表单新建（「大类」下拉不含「无父类」），新增统一走右上角「添加」。每个一级分组是一张独立白卡（`rounded-[18px]` + `overflow-hidden`），卡片之间留 12px 页面灰底间隔（`flex flex-col gap-3`），明显大于行间 1px 分隔线，避免不同组连成一片；标题是卡片顶部的**白底**分节带（`bg-panel` / 14px·600 / `text-ink-warm` #3f3f46 / h-8）：与整张白卡同色，只靠加深的标题文字和底部 1px `border-rule` 分隔线区分层级，不再用灰带，避免与 15px 黑字的子项行抢对比。

之后，避免监听方刷新时读到旧快照。先检查 `currentBookId`，未选账本时直接返回避免抛错。二级分类行的编辑笔与右上角「添加」共用同一个 `showCategoryEdit` 底部上滑抽屉（`edit.tsx` 的 `from: "bottom"`、`h-[84vh]`、`rounded-t-[28px]`），`form.tsx` 顶部还原 APK
