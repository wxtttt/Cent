## 首页概览卡的支出口径

- 左栏标题固定 `month-expense` =「本月支出」，**后面不带任何日期 / 周期范围**；不要改回「本期支出」。
- 金额按「当前日所在记账周期」统计：优先读覆盖今天的普通预算记录冻结边界，回落 `periodContaining(now, clampStartDay(startDay))`。周期本身的生成规则见 `docs/agents/budget.md`。
