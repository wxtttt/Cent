## 数据模型（`ledger/extra-type.ts`）

`SavedLoanPlan` 的四个可选字段（旧方案缺省按旧语义解释，不要改成必填）：

```ts
downMode?: "ratio" | "amount";       // 首付口径
downAmountWan?: number;              // 首付金额（万）
rateChanges?: SavedLoanRateChange[]; // { id, year, month, commercialRate, fundRate? }
prepays?: SavedLoanPrepay[];         // { id, year, month, amount(元), mode }
```

- 时间一律存**年月**，计算时换算成「首期起第几期」（`periodOfYm`）；越界事件丢弃。
- 提前还款 `mode`：`shorten`（缩年限）/ `reduceMonthly`（减月供）/ `payoff`（结清）。
- 提前还款、利率调整都是**即时落库**（`persist()` → `update()`），还款计划与进度一起重算；
  加一笔 20 万缩年限后计划从 30 年变 26 年，删掉又回到 30 年。

## 还款计划（`results.tsx: ScheduleCard`）

- 堆叠柱图 + 可滚动的年度行（`max-h-[286px]`），**图和表共用 `activeYear`**：
  点某一列 → 列表滚到该年（`scrollTo` 居中）并高亮；点某一年 → 该列点亮、其余列压暗（已还年份更暗）。
- 默认高亮当前年（`ceil(paid/12)`），列表挂载即滚到该年。
- 横轴三档：`第 1 年` / **`第 ceil(n/2) 年`（30 年即第 15 年）** / `第 n 年`。
- 年度行右侧的 ⌄ 单独展开 12 期月表（点行是「选中」，不再兼着展开）。
- 图例、币种、单位口径不变：`¥` + 千分位，「万」在拼文案时补。

## 计算（`ledger/loan.ts` 的 `buildSchedule`）

事件驱动的逐期摊还，`deriveLoan` 是唯一入口：

- **利率调整**：第 n 期起换利率。等额本息按「剩余本金 + 剩余期数」重算月供；等额本金只换利息。
- **提前还款**：第 n 期还款后扣减本金；`shorten` 用固定月供反解期数（`periodsFor`），
  `reduceMonthly` 用剩余期数求新月供，`payoff` 直接清零并记 `closedAt`。
- **组合贷**：两条轨各自跑；提前还款先冲商贷（利率高），余额不足的部分才落到公积金。
- **进度**：`periodsElapsed` 用首期年月到当前月（**不含当月**）计算已还期数，
  剩余本金取 `rows[paid-1].remaining`；`prepaySaved` = 无提前还款基线利息 − 实际利息。

## 视觉口径

- 页面底色 `dp-drawer-surface`（#f4f4f4 + 纯白卡），页头 18px semibold（与分类 / 预算管理页一致）。
- 详情与编辑都是「`GroupTitle` + 白卡」节奏：`GroupTitle` 12px 次级灰在卡外，卡用 `CARD` / `ListCard`；
  详情页把「剩余本金进度」与「下次还款」并进同一张卡（中间 `border-t border-rule/60` 分段），
  顺序是 还款进度 → 提前还款 → 利率轨迹 → 还款计划。
- **页面底栏用 `PAGE_FOOTER`，不要用 `SHEET_FOOTER`**：`PopupLayout` 已经垫过
  `--safe-area-inset-bottom`，抽屉底栏再叠一次会把「保存」/「提前还款」顶出可视区。
- **详情页根节点必须是 `flex min-h-0 flex-1 flex-col`**：写成 `h-full` 会把顶栏高度也算进 100%，
  底栏被挤出屏幕（用户报的「最下面按钮只露一点」）。
- 抽屉一律 `SheetShell`（内置拖拽条 / 17px 居中标题 / `SHEET_FOOTER`）；底栏是**两颗 `flex-1` 等宽按钮**
  （编辑态左侧换 `BTN_DANGER` 的「删除」），与「编辑特殊预算」完全一致。手写 Dialog 已全部删除。
- 中文标签不用 `font-semibold`；只有数字用 600/700。
- **保存成功不弹 toast**：抽屉关掉、页面数字变了就是反馈。行业常态如此，用户也明确嫌「已保存」丑。

## 已知缺口

- 提前还款的省息是「相对不做这笔」的总额差，多笔时无法拆到单笔；列表里单笔的「缩短 N 个月」是按单笔模拟估的。
- 组合贷的提前还款拆分按「先商贷后公积金」，与银行实际冲还顺序可能不同，文案已注明以银行为准。
- 方案名不会随缩期自动更新（仍是保存时的「210 万 · 30 年」）。
- 英文包沿用「万」作金额单位（贷款页全篇如此），未做 10k 换算。
