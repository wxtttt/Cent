## 设计评审（r35，用户问「有没有设计不好的地方」）

**APK 的问题**：① 「保存修改」静默覆盖已存方案且占底栏主按钮位，无确认无反馈，探索性调参误按即毁方案；② 修改后无任何脏态标记（chip / hero / 对比卡都不变），唯一信号是底栏按钮从「保存方案」变双钮；③ LPR 可自由编辑但页脚政策日期写死，自定义后口径自相矛盾；公积金「首套/二套政策卡 + 自由利率输入」双轨冗余；④ 还款方式三处控件同源（表单行 chips / 对比卡点选 / hero 形态），表单行与对比卡完全重复；⑤ 洞察条只比首月且文案不随选中态换视角（等额本金选中时仍在劝选等额本金），缺交叉年 / 前 N 年累计视角；⑥ 组合贷款只能改公积金反推商贷，公积金政策上限无校验提示；⑦ 年限滚轮 1–30 逐档无快捷片（我们旧版 10/20/30 快捷反而更好）；⑧ 金额无千分位、单位锁死「万」；⑨ 图表与年度行零联动（点柱无反应）；⑩ 无提前还款模拟——贷款工具最大功能缺口；⑪ 保存抽屉「选个图标」点按两次无响应（chip 上图标存在，疑似 bug）；⑫ 改名/删除藏顶栏 ⋯ 且无语义标签，可发现性差。

**APK 值得直接吸收**：hero 票券卡的信息密度与占比条、绿色洞察条形式、堆叠柱 + 年度行展开月表、保存抽屉预览摘要、删除确认的家人视角文案、无方案时默认下一月为首次还款。

## Web 实现口径（2026-11-16 落地）

- **金额单位**：房价 / 贷款额 / 公积金额度一律「万」，月供与逐期数字用「元」并带千分位（`fmtMoney` = `en-US` 两位小数）。**单位在拼文案时补**（`amount: `¥${fmtMoney(v)}``、`${fmtWan(v)} 万`），不写进语言包——写进语言包会让英文界面也长出「万」。已修过一版：洞察条曾渲染成「少付利息 14.43，但首月要多还 2,260.42」两处都没单位，`loan-decrease-note` / `loan-hero-sub-decrease` / `loan-prepay-saved` / `loan-prepay-new-monthly` 同样漏了 `¥`。
- **还款方式只在对比卡点选**（用户 r35 拍板②）：表单里没有「还款方式」行，`CompareCard` 两张卡 `data-loan-compare="installment|principal"` + 选中态橙描边；hero 形态（每月应还 ↔ 首月应还）、洞察条视角三处同源联动。洞察条会随选中态换视角（等额本金选中时劝等额本息），并给「第 N 期起等额本金月供更低」的交叉期提示——这是 APK 的缺陷⑤，别再退回单向文案。
- **滚动容器必须 `[&>*]:shrink-0`**：`form.tsx` 的 `flex flex-1 flex-col gap-4 overflow-y-auto` 里内容高于视口时，flex 子项默认 `shrink` 会把 hero 票券卡压成 **40px** 高（`scrollHeight` 222 / `getBoundingClientRect().height` 40，肉眼表现是 hero 只剩「每月应还」一行）。**加新卡片到这一列不用单独写 `shrink-0`**，容器上的 `[&>*]:shrink-0` 已兜住；但把卡片挪到别的 flex 列时别忘补。
- **提前还款模拟**（用户拍板①）：`PrepayCard` 三模式 `缩年限 / 减月供 / 一次性结清`，**组合贷款不渲染**（两轨利率不同、结清语义不唯一）。默认从第 12 期起、金额 20 万；结果条 `省利息 ¥…，缩短 N 个月`。
- **方案管理**：选中已存方案时顶栏出现 `⋯`（`data-loan-more`），抽屉两项——`修改名称和图标`（`save-sheet` 复用、名称预填）/`删除方案`（`providers.tsx` 的确认实例，文案带家人视角）；**chip 长按 550ms 也能进同一抽屉**（APK 只有顶栏入口、可发现性差，这里补了长按）。
- **脏态与保存**：`selected && dirty` 时底栏换成 `另存为新方案 / 保存修改` 双按钮（对齐 APK），`保存修改` 走 `useLoanPlans().update` 静默 patch + toast；未选中方案时单按钮 `保存方案`。
- **页脚口径**：`loan-page-disclaimer`（结果仅供参考）+ `loan-rate-note-policy` / `-custom`（改过 LPR 时显示「按自定义 LPR X% 计算」，未改显示政策日期 2026-09-20）。
- **图标资产**：`apps/cent/public/loan/*.webp`（13 张，3D 风），`icons.ts` 做「类型默认图标 + 方案自选图标」映射。

### 已知缺口

- 英文包里没有「万」这个概念，金额仍按 `14.43 万` 显示（`万` 目前硬编码在 JSX 里，与 zh/en 无关）；要做英文金额需要把「万」抽成语言键 + 按 locale 换单位。
- 深色模式未单独验（颜色都走 `bg-panel` / `bg-ground` / `text-ink` 令牌，理论上跟随；贷款页 hero 是暖色渐变常量，深色下未核对对比度）。
- 组合贷款的双轨利率在提前还款模拟里不适用，卡片直接不渲染；如需支持要先定「结清哪一轨」的语义。
